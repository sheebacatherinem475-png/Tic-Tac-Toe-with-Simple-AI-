# Tic-Tac-Toe with Simple AI 🎮

## 📌 Project Description
Tic-Tac-Toe with Simple AI is a Python-based game where a human player plays against a computer. The player uses **X**, and the computer uses **O**. The AI can try to win, block the player's winning move, and choose a random empty position.

This project is developed using Python and can be run in Jupyter Notebook.

## ✨ Features
- Simple and easy-to-play game.
- Human vs Computer gameplay.
- AI tries to make a winning move.
- AI blocks the player's winning move.
- Detects win, loss, and draw.
- Validates player input.
- Allows players to restart the game by running the program again.

## 🚀 How to Run the Project

1. Install Python and Jupyter Notebook.
2. Open Jupyter Notebook.
3. Create a new Python notebook.
4. Copy the project code into a cell.
5. Run the cell using **Shift + Enter**.
6. Enter a position from 1 to 9 when prompted.
7. Play against the computer.

## 🎯 Game Instructions

The board contains nine positions:

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

- You play as **X**.
- The computer plays as **O**.
- Enter a number from 1 to 9 to select a position.
- The first player to get three marks in a row, column, or diagonal wins.
- If all positions are filled and nobody wins, the game ends in a draw.

## 🧠 AI Logic

The computer follows these steps:

1. Checks whether it can win with its next move.
2. Blocks the player's winning move if necessary.
3. Otherwise, selects a random empty position.

This is a simple AI strategy and does not guarantee that the computer will win or never lose.
